CloudVPN+ REST API Specification
Exhaustive Endpoints Catalog, Nonce Protocols & Client Usage Mapping

Authentication Protocol Summary

All /adminPanel/ routes in ccserver.py require a computed passwd token. The token is calculated dynamically for each request as: 

1. Nonce Request: POST /admin/nonce with JSON payload {"UEmail": email} -> Returns {"nonce": integer}
2. Hash Computation: sha256(actualPassword + String(nonce)) -> 64-char hexadecimal digest
3. Endpoint Call: GET /adminPanel/route/{email}/{digest}/...

Administrative Endpoints Catalog

POST /admin/nonce

Description: Increments and returns the current nonce for the specified administrator email.

Request Body: {"UEmail": "root" | "admin@example.com"} (Transmitted as JSON payload).

Success Response (200 OK):

{"nonce": 14}

  • File: js/admin_api.js • Class/Object: CloudVPNApi • Function: getAdminNonce(email) and encodeNonce(email, actualPassword)
  • File: js/admin_dashboard.js • Function: Live Diagnostics runner
GET /adminPanel/loginVerification/{email}/{passwd}/

Description: Validates admin credentials using the computed hashed nonce password.

Path Parameters: email (Admin identity / email), passwd (SHA-256 hashed password + nonce).

Success Response (200 OK):

{"status": "success"}

Failure Response:

{"status": "error", "message": "Auth Fail"}
Used by:
  • File: js/admin_api.js • Object: CloudVPNApi • Function: verifyLogin(email, password)
