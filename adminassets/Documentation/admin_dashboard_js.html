File Documentation: admin_dashboard.js

Admin Dashboard UI Controller & State Management Specification

First: Necessity, Role, and Project Interaction

Why this file is necessary: admin_dashboard.js is the master controller for the CloudVPN+ administration UI. It coordinates real-time telemetry updates, manages tab navigation state, renders paginated user data, controls interactive modals for server and account operations, and displays feedback toasts.

How it fits into the project: It connects the DOM view elements defined in admin_dashboard.html with the data methods provided by admin_api.js and the authentication state in admin_auth.js.

How it interacts with the project:

  • Imports AdminAuth from js/admin_auth.js to enforce route security (requireAuth()).
  • Imports CloudVPNApi from js/admin_api.js to perform authenticated network calls.
  • Exposes the global controller object window.CloudVPNDashboard for inline HTML button triggers.

Second: Overall Project Structure & Architectural Context

admin_dashboard.js follows an event-driven Model-View-Controller architecture: 

                                     +-------------------------------+
                                     | admin_dashboard.html (View)   |
                                     +-------------------------------+
                                           |                    ^
                            User Actions   |                    | DOM Updates / Modals
                            (Clicks, Tabs) |                    |
                                           v                    |
                                     +-------------------------------+
                                     | admin_dashboard.js (Ctrl)     |
                                     +-------------------------------+
                                           |                    ^
                              API Requests |                    | JSON Responses
                                           v                    |
                                     +-------------------------------+
                                     | CloudVPNApi (admin_api.js)    |
                                     +-------------------------------+

Third: Detailed Breakdown of Functions, Classes, and Members

1. State & Cache Variables

  • currentSession (object | null): Active session object { email, password, loggedInAt }.
  • currentTab (string): Active tab identifier ('overview' | 'users' | 'servers' | 'diagnostics').
  • userPageStart (number): Offset pointer for user range pagination (default 0).
  • userPageSize (number): Number of users fetched per page slice (default 20).
  • cachedServers (Array<string>): In-memory list of registered server names.
  • cachedUsers (object): In-memory dictionary of user profiles.

2. Core Controller Functions

initDashboard()

  • Purpose: Primary lifecycle initialization function invoked when DOM is ready. Verifies auth session, populates navbar badges, registers event listeners, and triggers initial data queries.
  • Dependencies: imported AdminAuth from js/admin_auth.js (Calls requireAuth()).

formatBytes(bytes)

  • Purpose: Utility function converting raw byte integers into human-readable data strings (KB, MB, GB).
  • Data Types: bytes (number | string). Returns string (e.g. "12.45 MB").

showToast(type, message)

  • Purpose: Spawns a non-blocking, glassmorphic toast notification in #toastContainer with automatic 4-second timeout and fade-out animation.
  • Data Types: type ('success' | 'danger' | 'warning'), message (string). Returns void.

escapeHtml(str)

  • Purpose: Sanitizes dynamic text strings to prevent Cross-Site Scripting (XSS) when injecting server responses into innerHTML.
  • Data Types: str (string). Returns string.

setupTabNavigation() & switchTab(tabName)

  • Purpose: Manages sidebar tab button active classes and toggles visibility of tab pane sections (#tab-overview, #tab-users, #tab-servers, #tab-diagnostics).
  • Data Types: tabName (string). Returns void.

refreshAllData()

  • Purpose: Executes concurrent updates for server list and overview statistics via Promise.all.
  • Data Types: Returns Promise<void>.

loadServersView()

  • Purpose: Fetches routing servers from /adminPanel/serverquery/ via CloudVPNApi.fetchServers() and populates both the overview fleet grid and the full server registry table.
  • Dependencies: imported CloudVPNApi from js/admin_api.js.

loadOverviewStats()

  • Purpose: Queries user accounts from /adminPanel/listusers/ to calculate total users, active accounts, blocked accounts, and total bandwidth consumed.
  • Dependencies: imported CloudVPNApi from js/admin_api.js.

loadUsersTable()

  • Purpose: Requests a paginated range of users from /adminPanel/listusers/ based on userPageStart and renders the table rows with quota, remaining bandwidth, status badges, and action buttons.
  • Dependencies: imported CloudVPNApi from js/admin_api.js.

3. Action Modal Handlers

inspectUser(userEmail)

  • Purpose: Queries single user details from /adminPanel/query/{email}/{passwd}/{userEmail} and renders profile cards and raw JSON in #modalInspectUser.

promptRemoveServer(serverName)

  • Purpose: Configures #modalConfirm to delete the selected server node via CloudVPNApi.removeServer() upon administrator confirmation.

toggleBlockUser(userEmail, block)

  • Purpose: Dispatches account block (/adminPanel/blockUser/) or unblock (/adminPanel/unblockUser/) requests and refreshes the user directory.

promptChangeEmail(userEmail)

  • Purpose: Opens #modalChangeEmail and executes /adminPanel/changeUserEmail/ to migrate user data to a new email address.

promptDeleteUser(userEmail)

  • Purpose: Configures #modalConfirm to delete the selected user via CloudVPNApi.deleteUser().
