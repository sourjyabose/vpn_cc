File Documentation: index.html

Router & Portal Entrance Specification

First: Necessity, Role, and Project Interaction

Why this file is necessary: When ccserver.py receives an HTTP GET request to the root path /, its wildcard route handler @server.get("/{path:path}") matches with path == "" and returns FileResponse("index.html"). Without index.html, users navigating to the server root would encounter a missing file error.

How it fits into the project: index.html acts as an automated client-side router. It checks whether the user has an active, authenticated administrative session in sessionStorage. If a session is present, it redirects the browser to admin_dashboard.html; otherwise, it redirects to admin_login.html.

How it interacts with the project: It imports admin_auth.js to invoke AdminAuth.getSession(). It links to css/admin_style.css to ensure a seamless visual transition during redirection.

Second: Overall Project Structure & Architectural Context

The project architecture separates presentation, routing, authentication, and communication. index.html resides at the top of the frontend hierarchy as the default entry point. 

Client Request (GET /) -> ccserver.py root() -> Returns index.html

Third: Detailed Breakdown of Functions, Scripts, and Members

Inline Script: DOMContentLoaded Router

  • Function / Event Handler: document.addEventListener('DOMContentLoaded', () => { ... })
  • Purpose: Executes immediately upon DOM initialization to assess authentication status and dispatch the window location.
  • Inputs: None.
  • Return Value: void.
  • Imported Dependencies:
    • imported AdminAuth from js/admin_auth.js (Used to call AdminAuth.getSession() to verify whether credentials exist in sessionStorage).
    • imported window.location from browser DOM API (Used to invoke window.location.replace() to navigate without polluting browser history).

HTML Components and Elements

  • <div class="wallpaper-veil">: Renders the translucent overlay over the background image.
  • <div class="glass-panel login-card">: Displays a frosted glass placeholder with the CloudVPN+ logo while the redirection executes.
