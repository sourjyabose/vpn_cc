1. Project Overview & Business Purpose

CloudVPN+ is a modern, high-speed virtual private network and bandwidth management portal designed to provide users with secure, rapid onboarding, credential management, and instant mobile data bandwidth top-ups. The client frontend delivers an extraordinary aesthetic experience using a light-themed Glassmorphism UI floating over a high-resolution classical landscape art canvas.

Strict UI & Environment Constraints:
  • Light Theme Only: Crisp frosted glass surface atop warm classical scenery.
  • Color Constraints: Zero purple, zero blue, zero pink. Warm amber/ochre/charcoal tones are utilized.
  • No Color Gradients: Solely solid colors and solid translucent alpha levels (`rgba`, `rgb`, `hsl`).
  • 50/50 Split Viewport: Left 50% remains completely clear to showcase the classical artwork, right 50% contains the floating glass card.
  • HTTP Compatibility: Strictly zero HTTPS-exclusive APIs (No Service Workers, no `crypto.subtle`), standard web features only.
  • Decoupled Backend Architecture: Zero hardcoded backend dependencies. Clean REST API interfaces ready for user backend attachment.

3. System Architecture & Component Interaction

The system is architected in a modular 4-tier client-side design pattern:

Tier / Layer Component Files Core Responsibility
1. Presentation & Structure Layer signup.html, login.html, recharge.html Semantic HTML5 markup structured into 50/50 split layout, input fields, labels, accessible error containers, and modals.
2. Visual Styling & Glass Layer css/style.css Implements frosted glassmorphic card (backdrop-filter: blur(16px)), solid light palette, zero purple/blue/pink, zero gradients, WCAG AAA text contrast.
3. Client Validation & Controller Layer js/validation.js, js/auth.js, js/recharge.js Handles input sanitization, RFC email regex, password matching, DOM feedback rendering, plan selection (1gb to 10gb), and the login_succ() global workflow.
4. API Abstraction & Session Layer js/api_client.js HTTP-compatible async API client interfacing with backend endpoints (/auth/signup, /auth/login, /recharge/process), token storage, and offline mock fallback.

4. Architectural Decisions & Rationale

Why Glassmorphism with 50/50 Split?

The background provided by the user is an exquisite, historic Indian miniature painting representing royalty, gardens, and water architecture. Obscuring this visual with full-width solid forms would ruin the aesthetic appeal. By fixing the canvas at 50% left visibility and floating a frosted glass card (rgba(255, 255, 255, 0.82) with backdrop-filter: blur(16px)) on the right, the user experiences a modern digital tool while appreciating the artwork beneath.

Why Zero Purple, Blue, Pink, or Gradients?

The user strictly prohibited shades of purple, blue, pink, and any color gradients. To create a prestigious, clean, and regal corporate feel that harmonizes with the background painting, we selected a palette composed of:

  • Ivory / Porcelain Glass: rgba(255, 255, 255, 0.82) and rgba(252, 250, 246, 0.72).
  • Deep Warm Charcoal / Black Text: #1c1917 and #44403c for ultra-crisp readability.
  • Warm Amber / Earthy Gold: #b45309, #92400e, and #78350f for primary brand accents and interactive states.
  • Dark Brick Red & Forest Green: #991b1b and #166534 for high-contrast, non-pink/non-purple validation feedback.

Why HTTP Compatibility Only?

When hosting over unencrypted HTTP (port 80 or local network), modern web browsers disable features marked as "Powerful Features requiring Secure Context" (e.g. Service Workers, window.crypto.subtle, Web Bluetooth, Web MIDI). All CloudVPN+ code utilizes standard ECMAScript 6+ vanilla DOM APIs, localStorage, sessionStorage, and standard fetch calls with JSON payloads, ensuring 100% crash-free execution over standard HTTP.

How login_succ() Operates

As requested, when successful authentication occurs (or when the developer executes login_succ() programmatically or via testing buttons), the global function updates the user's local session cache, renders an active feedback banner in the glassmorphic card, and smoothly transitions to recharge.html.
