POST /api/v1/auth/signup

Description: Registers a new user account with CloudVPN+.

Usage Mapping

  • Consuming File: js/api_client.js & js/auth.js
  • Consuming Class: CloudVPNAPIClient
  • Consuming Function: async signup(payload)

Request Headers

Content-Type: application/json
Accept: application/json

Request Payload Schema (JSON)

{
  "email": "user@example.com",        // string, required (valid email format)
  "password": "StrongPassword123"      // string, required (min 8 chars, alphanumeric)
}

Success Response (201 Created / 200 OK)

{
  "status": "success",
  "message": "Account created successfully",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "usr_98124",
    "email": "user@example.com",
    "createdAt": "2026-08-26T17:15:00Z"
  }
}

Error Response (400 Bad Request / 409 Conflict)

{
  "status": "error",
  "message": "An account with this email address already exists."
}

cURL Example

curl -X POST http://localhost:8080/api/v1/auth/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"test@cloudvpn.plus","password":"SecretPassword1"}'
POST /api/v1/auth/login

Description: Authenticates existing user credentials and returns a session token. Upon receipt, triggers window.login_succ().

Usage Mapping

  • Consuming File: js/api_client.js & js/auth.js
  • Consuming Class: CloudVPNAPIClient
  • Consuming Function: async login(payload), invokes window.login_succ(response)

Request Payload Schema (JSON)

{
  "email": "user@example.com",        // string, required
  "password": "UserPassword123"       // string, required
}

Success Response (200 OK)

{
  "status": "success",
  "message": "Authentication successful",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "usr_789456",
    "email": "user@example.com",
    "lastLogin": "2026-08-26T17:15:00Z"
  }
}

Error Response (401 Unauthorized)

{
  "status": "error",
  "message": "Invalid email or password."
}

cURL Example

curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@cloudvpn.plus","password":"SecretPassword1"}'
POST /api/v1/recharge/process

Description: Processes a high-speed data quota top-up for the active account.

Usage Mapping

  • Consuming File: js/api_client.js & js/recharge.js
  • Consuming Class: CloudVPNAPIClient
  • Consuming Function: async processRecharge(payload)

Request Headers

Content-Type: application/json
Accept: application/json
Authorization: Bearer <auth_token>

Request Payload Schema (JSON)

{
  "plan": "1.5gb",                    // string, required (options: '1gb', '1.5gb', '2gb', '5gb', '10gb')
  "amount": "$2.99",                  // string, required
  "userEmail": "user@cloudvpn.plus"   // string, required
}

Success Response (200 OK)

{
  "status": "success",
  "transactionId": "TXN_7849201",
  "plan": "1.5gb",
  "amount": "$2.99",
  "timestamp": "2026-08-26T17:15:00Z",
  "message": "Recharge completed successfully for plan 1.5gb"
}

cURL Example

curl -X POST http://localhost:8080/api/v1/recharge/process \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer mock_jwt_token_123" \
  -d '{"plan":"2gb","amount":"$3.99","userEmail":"user@cloudvpn.plus"}'
