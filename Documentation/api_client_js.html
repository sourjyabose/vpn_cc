File Documentation: api_client_js.html

Target File: js/api_client.js | Type: ECMAScript 6 REST API Service Layer

First: Purpose, Necessity & Project Fit

Why this file is necessary: In keeping with the strict project requirement ("Don't write any backend code it will be written only and only by me"), api_client.js isolates all HTTP network communication into a clean, decoupled abstraction layer. When the user builds their custom backend, they do not need to alter any UI DOM code; they simply configure the endpoint URLs in this client.

How it fits into the project: It sits between the user interface controllers (auth.js, recharge.js) and the external HTTP server.

How it interacts with the project:

  • Exposes a global singleton window.CloudVPNAPI.
  • Manages session tokens and authenticated user metadata via browser localStorage / sessionStorage.
  • Dispatches HTTP JSON requests using standard fetch() API.
  • Includes a graceful fallback handler (_mockFallback) allowing the frontend to be fully interactive even prior to backend deployment.

Second: Project Structure, Architecture & Design Rationale

Architecture & Design Rationale: Implements the Client Adapter Pattern. By centralizing HTTP headers, bearer tokens, error parsing, and serialization in one class (CloudVPNAPIClient), other modules remain concise and focused exclusively on UI logic.
