File Documentation: admin_api.js

CloudVPN+ Admin API Communication Client Specification

First: Necessity, Role, and Project Interaction

Why this file is necessary: admin_api.js encapsulates all REST API network operations between the frontend and the ccserver.py FastAPI backend. It provides automated Base URL extraction, nonce retrieval via XMLHttpRequest, SHA-256 token generation, and strongly typed wrapper methods for all ten /adminPanel/ routes.

How it fits into the project: It decouples UI views from direct network requests. Both admin_auth.js and admin_dashboard.js rely entirely on CloudVPNApi to communicate with the server.

How it interacts with the project:

  • Imports sha256 from js/sha256.js to compute the dynamic token in encodeNonce().
  • Provides API services to admin_auth.js (login verification).
  • Provides API services to admin_dashboard.js (server management, user listing, pagination, blocking, deleting, and email updates).

Second: Overall Project Structure & Architectural Context

admin_api.js acts as the client gateway. Before executing any administrative GET request, it transparently triggers the nonce handshake: 

Caller (admin_auth.js or admin_dashboard.js)
                      |
                      v
CloudVPNApi.adminGetRequest(routeTemplate, adminEmail, adminPassword)
                      |
                      +---> Step 1: CloudVPNApi.encodeNonce(adminEmail, adminPassword)
                      |         |
                      |         +---> CloudVPNApi.getAdminNonce(adminEmail) 
                      |         |        [XHR GET /admin/nonce with {"UEmail": email}]
                      |         |
                      |         +---> sha256(adminPassword + nonce) -> digestToken
                      |
                      +---> Step 2: url = routeTemplate(adminEmail, digestToken)
                      |
                      +---> Step 3: XHR GET url -> Returns parsed JSON response
                      |
                      v
Promise resolves with server payload {status: "success", ...}

Third: Detailed Breakdown of Functions and Members in CloudVPNApi

1. getBaseUrl()

  • Purpose: Extracts the protocol and host from window.location or retrieves an override URL from sessionStorage.
  • Data Types: Takes no arguments. Returns string (e.g., "http://localhost:8000").
  • Rationale: Enables zero-config hosting on any port or domain without hardcoding backend endpoints.

2. setCustomBaseUrl(url)

  • Purpose: Saves or removes a custom Base URL in sessionStorage.
  • Data Types: url (string). Returns void.

3. getAdminNonce(email)

  • Purpose: Issues an HTTP GET request to /admin/nonce transmitting the JSON body {"UEmail": email} via XMLHttpRequest.
  • Why Needed: ccserver.py defines @server.get("/admin/nonce") expecting req = await request.json(). Because standard browser fetch() disallows body payloads on GET requests, XMLHttpRequest is used.
  • Data Types: email (string). Returns Promise<number> resolving to the incremented nonce integer.
  • Error Handling: Catches HTTP errors, non-JSON responses, and connection refusals.

4. encodeNonce(email, actualPassword)

  • Purpose: Executes the nonce retrieval and computes sha256(actualPassword + String(nonce)).
  • Translation of Python: 
    def encodeNonce(email, value):
    nonce = requests.get(url + "/admin/nonce", json={"UEmail": email}).json()["nonce"]
    return hashlib.sha256((value + str(nonce)).encode("utf-8")).hexdigest()
  • Data Types: email (string), actualPassword (string). Returns Promise<string> (64-char hex string).
  • Imported Dependencies: imported sha256 from js/sha256.js (Cryptographic SHA-256 calculation).

5. adminGetRequest(routeTemplate, adminEmail, adminPassword)

  • Purpose: Core executor for all administrative requests. Handles fresh nonce token computation, URL resolution, and JSON parsing.
  • Data Types:
    • routeTemplate (function(string, string): string): Factory returning target endpoint URL.
    • adminEmail (string): Admin username or email.
    • adminPassword (string): Admin password.
    • Returns: Promise<object>: Parsed server JSON response.
