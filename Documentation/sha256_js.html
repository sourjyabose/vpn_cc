File Documentation: sha256.js

Pure JavaScript Cryptographic SHA-256 Algorithm Specification

First: Necessity, Role, and Project Interaction

Why this file is necessary: Modern browsers restrict the Web Cryptography API (window.crypto.subtle) to Secure Contexts (HTTPS and localhost). When CloudVPN+ is deployed over plain HTTP on remote IP addresses or non-secure origins, crypto.subtle is undefined. sha256.js is a zero-dependency, self-contained pure JavaScript implementation of the NIST FIPS 180-4 SHA-256 standard, enabling reliable password token hashing in all HTTP browser environments.

How it fits into the project: It translates the Python hashing logic: 

hashlib.sha256((value + str(nonce)).encode("utf-8")).hexdigest()
into client-side JavaScript, guaranteeing byte-for-byte output equivalence.

How it interacts with the project: It is loaded before admin_api.js and exposes the global function window.sha256(input) (or CommonJS module.exports in Node environments). CloudVPNApi.encodeNonce() directly calls sha256() to construct authenticated route URLs.

Second: Overall Project Structure & Architectural Context

sha256.js operates at the foundational cryptographic utility layer: 

[User Password & Server Nonce]
              |
              v
[js/sha256.js: sha256(password + nonce)]
              |
              +---> [utf8Encode(input)] -> Converts string to Uint8Array UTF-8 bytes
              |
              +---> [rawSha256(bytes)]
                       |
                       +-- Padding (0x80 + 64-bit length)
                       +-- 512-bit Chunk Processing
                       +-- 64-Round Expansion & Compression (Ch, Maj, Sigma0, Sigma1)
                       +-- Hexadecimal Digest Assembly (8 x 32-bit words)
              |
              v
[64-Character Hex String Token] ---> [Used by js/admin_api.js for GET Requests]

Third: Detailed Breakdown of Functions, Classes, and Members

1. utf8Encode(str)

  • Purpose: Encodes a JavaScript UTF-16 string into a UTF-8 byte array (Uint8Array), correctly parsing ASCII, multi-byte characters, and surrogate pairs.
  • Why Needed: SHA-256 operates on raw UTF-8 byte streams. Direct charCodeAt() indexing without UTF-8 expansion would produce incorrect hashes for non-ASCII characters.
  • Data Types:
    • Input: str (string) - Input string to be encoded.
    • Returns: Uint8Array - Byte array representing UTF-8 stream.
  • Variables:
    • utf8 (Array<number>): Dynamic array collecting byte values.
    • charcode (number): Unicode code point value.
  • Dependencies: Falls back to manual bit-shifting if window.TextEncoder is unavailable.

2. rawSha256(bytes)

  • Purpose: Executes the 64-round SHA-256 compression pipeline over padded 512-bit message blocks.
  • Why Needed: Computes the core cryptographic hash transformation.
  • Data Types:
    • Input: bytes (Uint8Array) - Raw UTF-8 bytes.
    • Returns: string - 64-character lowercase hexadecimal hash.
  • Internal Constants & State Variables:
    • K (Array<number>): 64 round constant 32-bit words derived from the fractional parts of cube roots of the first 64 primes.
    • H0 through H7 (number): Initial 32-bit state words derived from fractional parts of square roots of first 8 primes.
    • byteLen (number): Original input length in bytes.
    • bitLen (number): Original input length in bits (byteLen * 8).
    • newLen (number): Padded length aligned to 64-byte (512-bit) boundaries.
    • padded (Uint8Array): Message buffer containing original bytes, separator byte 0x80, and 64-bit big-endian bit length.
    • view (DataView): DataView wrapper used to safely write 64-bit length into buffer.
    • W (Uint32Array(64)): Message schedule array expanded per 512-bit block.
    • a, b, c, d, e, f, g, h (number): Working variables updated during the 64 compression rounds.
  • Bitwise Operators: Uses >>> 0 extensively to coerce JavaScript numbers into 32-bit unsigned integers.

3. rightRotate(val, amount)

  • Purpose: Performs a 32-bit circular right rotation: ((val >>> amount) | (val << (32 - amount))) >>> 0.
  • Data Types:
    • Input: val (number, 32-bit uint), amount (number, bit shift count).
    • Returns: number (Rotated 32-bit uint).

4. sha256(input)

  • Purpose: Primary public entry point exposed globally on window.sha256 or module.exports.
  • Data Types:
    • Input: input (string | Uint8Array | any).
    • Returns: string - 64-character hexadecimal digest.
  • Interactions: Called by CloudVPNApi.encodeNonce() in admin_api.js.
