File Specification

File Documentation: login_html.html

Target File: login.html | Type: HTML5 Document

First: Purpose, Necessity & Project Fit

Why this file is necessary: login.html provides the authentication gateway for existing CloudVPN+ users. It allows registered members to submit credentials (email and password), verify authorization, and transition to the data management and recharge dashboard. It also implements the required global login_succ() execution workflow.

How it fits into the project: It serves as the primary return portal for users after signup or when revisiting the application. It acts as the initiator for user sessions and connects directly to recharge.html upon successful validation.

How it interacts with the project:

  • Styling Interaction: Linked to css/style.css to maintain layout consistency with the floating glassmorphic card on the right side and unobstructed background on the left.
  • Validation Interaction: Employs js/validation.js to ensure valid email formats before dispatching requests.
  • API Interaction: Interfaces with js/api_client.js to invoke CloudVPNAPI.login().
  • Workflow Hook Interaction: Interacts with js/auth.js which declares the required global window.login_succ() function.

Second: Project Structure, Architecture & Design Rationale

Architecture & Layout: Matches the design architecture of signup.html with a 50/50 split layout. The left half displays the classical Mughal artwork without any overlay, while the right half features a frosted glass card (backdrop-filter: blur(16px), rgba(255, 255, 255, 0.82)). In compliance with the design rules, no purple, blue, pink, or color gradients are used.

The login_succ() Mechanism: To fulfill the requirement that successful login is indicated by calling login_succ(), the page provides both programmatic and manual triggers for this function, ensuring instant integration with external backend responses.
