File Documentation: admin_login.html

Admin Login View & Authentication Interface Specification

First: Necessity, Role, and Project Interaction

Why this file is necessary: admin_login.html provides the primary administrative authentication user interface for CloudVPN+. It allows system operators to securely enter credentials (either username root or valid administrator email addresses) and authenticate against ccserver.py using the single-use nonce handshake.

How it fits into the project: It serves as the gateway to the administration portal. It enforces client-side identity validation, computes SHA-256 password digests with dynamic server nonces, transmits credentials to /adminPanel/loginVerification/{email}/{passwd}/, and establishes the local session upon successful verification.

How it interacts with the project:

  • Imports css/admin_style.css for light-theme glassmorphism styling atop assets/images/bg.jpg.
  • Imports js/sha256.js for pure JavaScript cryptographic hashing.
  • Imports js/admin_api.js to handle communication with /admin/nonce and /adminPanel/loginVerification/.
  • Imports js/admin_auth.js to perform input validation, session creation, and page navigation to admin_dashboard.html.

Second: Overall Project Structure & Architectural Context

The authentication flow connects the view layer to the cryptography and API layers, and then communicates with FastAPI over plain HTTP: 

[admin_login.html User Input]
      |
      v
[AdminAuth.validateAdminIdentity('root' or valid email?)]
      | (Valid)
      v
[CloudVPNApi.verifyLogin(identity, password)]
      |
      +---> [CloudVPNApi.getAdminNonce(identity)] -> GET /admin/nonce -> ccserver.py (Returns nonce)
      |
      +---> [sha256(password + nonce)] -> Computes 64-char hex digest token
      |
      +---> GET /adminPanel/loginVerification/{identity}/{digest}/ -> ccserver.py
      |
      v
[Server Status Check]
      |-- Success: AdminAuth.saveSession() -> Redirects to admin_dashboard.html
      \-- Failure: Render error message in #loginAlert box

Third: Detailed Breakdown of Functions, Elements, and Event Handlers

1. Form Submission Handler

  • Event: loginForm.addEventListener('submit', async (e) => { ... })
  • Purpose: Intercepts standard HTML form submission, executes identity validation, communicates with the authentication module, and updates UI feedback.
  • Inputs: Standard SubmitEvent object from form submission.
  • Return Value: Promise<void>.
  • Imported Dependencies:
    • imported AdminAuth from js/admin_auth.js (Used to call AdminAuth.validateAdminIdentity(), AdminAuth.validatePassword(), and AdminAuth.login()).
    • imported window.location from DOM API (Used to navigate to admin_dashboard.html upon successful authentication).
  • Variables:
    • identity (string): Sanitized value from #adminIdentityInput.
    • password (string): Raw password string from #adminPasswordInput.
    • idValidation (object): Validation result with isValid: boolean and message: string.
    • pwValidation (object): Password presence result with isValid: boolean.
    • result (object): Authentication response with success: boolean and optional message: string.

2. Password Visibility Toggle

  • Event: btnTogglePassword.addEventListener('click', () => { ... })
  • Purpose: Toggles input element type between 'password' and 'text', updating SVG eye icons.
  • Variables:
    • iconEyeOpen (SVGElement): SVG icon visible when password is obscured.
    • iconEyeClosed (SVGElement): SVG icon visible when password is plain text.

3. Real-Time Input Error Clearers

  • Events: identityInput.addEventListener('input', ... ) and passwordInput.addEventListener('input', ... )
  • Purpose: Dynamically clears is-invalid CSS classes and hides error alert boxes as soon as the user modifies input text.

4. DOM Elements

  • #adminLoginForm (HTMLFormElement): Form container with novalidate attribute.
  • #adminIdentityInput (HTMLInputElement): Text input for username or email.
  • #adminPasswordInput (HTMLInputElement): Password input field.
  • #loginAlert (HTMLDivElement): Frosted glass alert container displaying server error messages.
  • #btnLoginSubmit (HTMLButtonElement): Primary action button disabled during active nonce retrieval.
