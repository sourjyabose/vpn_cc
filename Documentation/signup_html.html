File Specification

File Documentation: signup_html.html

Target File: signup.html | Type: HTML5 Document

First: Purpose, Necessity & Project Fit

Why this file is necessary: signup.html provides the primary onboarding interface for the CloudVPN+ platform. It allows prospective users to create an account by providing their email address and configuring a secure password with a confirmation check. Without this file, new users would be unable to register credentials for the VPN service.

How it fits into the project: It serves as the primary gateway page of the application, linked directly from index.html and accessible from the login screen. It embeds the visual assets and script dependencies that orchestrate the client registration lifecycle.

How it interacts with the project:

  • Styling Interaction: Linked to css/style.css to render the 50/50 split canvas and the right-side light glassmorphic card.
  • Asset Interaction: References assets/images/bg.jpg as the fixed background canvas.
  • Validation Interaction: Interacts with js/validation.js to perform RFC 5322 email syntax validation, password complexity checking, and password matching verification.
  • API Interaction: Interacts with js/api_client.js and js/auth.js to dispatch asynchronous registration requests to the backend endpoint /auth/signup.
  • Navigation Interaction: Provides a hyperlink transition to login.html for registered members.

Second: Project Structure, Architecture & Design Rationale

Overall Project Structure: signup.html resides at the root level of the web application directory. It is structured to be completely static, requiring no pre-processors or build tools, making it 100% compatible with standard HTTP hosting.

Architectural Design & Rationale:

  • 50/50 Split Viewport: The document layout is split into two distinct structural containers using CSS flexbox. The left container (.left-scene-panel) remains 100% transparent to showcase the classical artwork, while the right container (.right-glass-panel) hosts the floating glass card (.glass-card).
  • High Contrast & No Gradients: Designed strictly with solid text colors (#1c1917, #44403c) and solid amber brand accents (#b45309). Zero purple, zero blue, and zero pink shades are used.
  • Accessible Semantic Markup: Includes ARIA attributes (role="alert", aria-live="polite") and explicit <label for="..."> tags for full screen-reader compliance.
