Controller Specification

File Documentation: recharge_js.html

Target File: js/recharge.js | Type: ECMAScript 6 Bandwidth & Recharge Controller

First: Purpose, Necessity & Project Fit

Why this file is necessary: recharge.js manages the interactive plan selection, pricing display, transaction dispatching, and confirmation receipt rendering for the CloudVPN+ high-speed data recharge system.

How it fits into the project: It powers the business logic for recharge.html, binding the required data plan tiers (1gb, 1.5gb, 2gb, 5gb, 10gb) to live UI summary cards and backend transaction endpoints.

How it interacts with the project:

  • Reads user session metadata from CloudVPNAPI.getCurrentUser() (in api_client.js) to display member status.
  • Listens to changes on the #planSelect dropdown in recharge.html.
  • Dispatches recharge orders via CloudVPNAPI.processRecharge().
  • Controls visibility of the receipt modal dialog (#rechargeModal).

Second: Project Structure, Architecture & Design Rationale

Architecture & Design Rationale: Encapsulates data tiers into an immutable data map (PLAN_DATA). When users select different options in the dropdown, the view is updated reactively without any page reloads or external library overhead.

Imported Dependencies:

  • imported CloudVPNAPI from api_client.js (reason: needed to query the active authenticated session, dispatch recharge transactions, and clear session on sign out).

Functions & Event Handlers

Function / Handler Parameters Return Type Comprehensive Specification
updatePlanCard(planKey) planKey: string (e.g. '1gb') void What it does: Looks up the corresponding record in PLAN_DATA and updates the DOM text content of #planAmount, #planValidity, and #planSpeed.
Why needed: Gives users instant visual feedback on plan pricing and specifications when selecting options in the dropdown.
Interactions: Executed on page load and on every dropdown change event.
rechargeForm Submit Listener e: SubmitEvent Promise<void> What it does: Prevents default submit, calls CloudVPNAPI.processRecharge() with plan details, populates the receipt modal with transaction ID, and opens the modal.
Interactions: Triggers POST /recharge/process API call.
