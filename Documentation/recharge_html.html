File Specification

File Documentation: recharge_html.html

Target File: recharge.html | Type: HTML5 Document

First: Purpose, Necessity & Project Fit

Why this file is necessary: recharge.html is the operational hub of the CloudVPN+ application. It allows authenticated users to top up high-speed VPN data quota by choosing from predefined bandwidth tiers (1gb, 1.5gb, 2gb, 5gb, and 10gb). It provides live pricing calculation and receipt confirmation.

How it fits into the project: It is the primary target destination following successful login (triggered by login_succ()). It represents the core transaction interface of the service.

How it interacts with the project:

  • Styling Interaction: Linked to css/style.css for 50/50 split layout, frosted glass card, custom select dropdown styling, and modal overlay.
  • Session Interaction: Reads user session state from CloudVPNAPI.getCurrentUser() to display the active member's account.
  • Controller Interaction: Driven by js/recharge.js which computes plan breakdowns and handles the receipt modal.
  • API Interaction: Interacts with js/api_client.js via CloudVPNAPI.processRecharge().

Second: Project Structure, Architecture & Design Rationale

Architecture & Design Rationale: Maintains visual parity with signup.html and login.html by keeping the left 50% clear for the classical painting and floating a glassmorphic card on the right 50%.

Required Dropdown Specifications: The dropdown includes the exact required options:

  • 1gb (Express Pass — $1.99, 24 Hours)
  • 1.5gb (Plus Pass — $2.99, 48 Hours)
  • 2gb (Weekly Boost — $3.99, 7 Days)
  • 5gb (Ultra Shield — $7.99, 30 Days)
  • 10gb (Enterprise Max — $12.99, 60 Days)

Light Theme & Color Compliance: Completely free of purple, blue, and pink. Features warm solid amber/gold accents (#b45309) and high-contrast charcoal text.
