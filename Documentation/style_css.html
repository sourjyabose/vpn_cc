Stylesheet Specification

File Documentation: style_css.html

Target File: css/style.css | Type: Cascading Style Sheet

First: Purpose, Necessity & Project Fit

Why this file is necessary: style.css serves as the central visual engine of the entire CloudVPN+ web application. It encapsulates the core glassmorphic styling, floating card geometry, responsive layout constraints, high-contrast typography, and strict color guardrails.

How it fits into the project: Every HTML page (signup.html, login.html, recharge.html) imports style.css to ensure absolute visual consistency across all user touchpoints.

How it interacts with the project:

  • Binds the classical artwork assets/images/bg.jpg to the viewport background with fixed attachment and cover scaling.
  • Defines CSS variables in :root that are referenced across all UI components.
  • Controls dynamic classes applied by JavaScript (e.g. .is-valid, .is-invalid, .hidden).

Second: Project Structure, Architecture & Design Rationale

Design System Principles:

  • Strict Color Compliance: Prohibits any shades of purple, blue, or pink. Uses warm ivory, rich charcoal (#1c1917), deep amber (#b45309), and natural earth tones.
  • No Color Gradients: Color properties are defined strictly using solid hex and alpha-blended solids (rgba), preventing multi-color gradients.
  • Glassmorphism Physics: Uses backdrop-filter: blur(16px) and -webkit-backdrop-filter: blur(16px) with high-opacity white backgrounds (rgba(255, 255, 255, 0.82)) and crisp solid border strokes (1px solid rgba(255, 255, 255, 0.95)) to ensure high text contrast.
  • 50/50 Split Viewport Architecture: Uses Flexbox (.left-scene-panel and .right-glass-panel) to keep the left side completely unobstructed and float the card on the right side.

CSS Custom Properties (Variables)

Variable Name Type / Value Purpose & Usage
--glass-bg rgba(255, 255, 255, 0.82) Primary frosted glass card background. Ensures text contrast over artwork.
--glass-border rgba(255, 255, 255, 0.95) Crisp border highlight giving the glass panel a sharp, floating physical edge.
--text-primary #1c1917 (Solid Charcoal) Deep high-contrast font color for headings, labels, and primary body text.
--text-secondary #44403c (Solid Stone) Subtitles, secondary labels, and descriptive notes.
--brand-primary #b45309 (Solid Amber) Primary action buttons, brand badges, and active focus highlights.
--brand-hover #92400e (Solid Dark Amber) Button hover state color.
--brand-light #fef3c7 (Solid Warm Cream) Background for status badges and user account strips.
--status-error-text #991b1b (Solid Brick Red) High contrast error messages (no pink).
--status-success-text #166534 (Solid Forest Green) Success feedback text and validation indicators.
--shadow-floating 0 20px 45px rgba(28,25,23,0.16)... Multi-layered box-shadow creating the physical floating elevation effect.

Major CSS Classes & Component Rules

Class Selector Target HTML Element Behavior & Visual Attributes
.scene-viewport <main> Full-screen background container binding bg.jpg.
.split-layout <div> Flex container dividing horizontal space 50/50.
.left-scene-panel <section> Left 50% container with pointer-events: none, keeping artwork unobstructed.
.right-glass-panel <section> Right 50% flex container centering the floating glass card.
.glass-card <div> Card element with backdrop-filter: blur(16px), 22px rounded corners, and floating shadow.
.form-input <input> Input control with rgba(255,255,255,0.92) background and transition effects.
.form-input.is-valid <input> Applies solid green border and light green tint when field passes validation.
.form-input.is-invalid <input> Applies solid red border and light red tint when field fails validation.
.btn-primary <button> Solid amber action button with hover elevation and active press states (strictly no gradients).
.modal-overlay <div> Fixed fullscreen backdrop (rgba(28,25,23,0.6)) for recharge receipt dialogs.
