File Documentation: admin_style.css

Glassmorphism Light-Theme Stylesheet & UI Design Specification

First: Necessity, Role, and Project Interaction

Why this file is necessary: admin_style.css provides the complete visual styling, glassmorphism rendering, typography, responsive layout rules, form styling, table layouts, and modal transitions for the entire CloudVPN+ Admin Portal.

How it fits into the project: It unifies the look and feel across index.html, admin_login.html, and admin_dashboard.html. It ensures all components render as distinct, luminous frosted glass panels atop the lush background image (assets/images/bg.jpg) with optimum legibility.

Strict Constraints Compliance:

  • Light Theme: High-luminosity surfaces with crisp dark slate text.
  • Zero Gradients: Strictly avoids any linear-gradient, radial-gradient, or conic-gradient functions. All backgrounds and accents use solid colors or solid-translucent rgba values.
  • Strictly No Purple, Blue, or Pink: Excludes all purple, indigo, lavender, violet, blue, cyan, navy, pink, magenta, and rose tones. Utilizes an emerald green, dark slate, amber, crimson, and translucent white color palette.
  • Zero Emojis: Visual cues are rendered solely using scalable vector SVG stroke icons.

Second: Overall Project Structure & Architectural Design

The stylesheet is organized into functional CSS modules using CSS Custom Properties (Variables): 

CSS Architecture Layers:
1. CSS Custom Properties (:root) -> Centralized theme tokens, colors, radiuses, shadows
2. Base & Reset Rules (*, body, html) -> Fixed wallpaper background and brightening veil
3. Glassmorphic Surface Utilities (.glass-panel, .glass-panel-subtle, .glass-panel-hover)
4. Vector Iconography Base (.svg-icon, .svg-icon-lg)
5. Layout Containers (.login-container, .dashboard-app, .dashboard-main)
6. Component Blocks (Navbar, Sidebar, Stat Cards, Form Inputs, Buttons, Tables, Badges, Modals, Toasts)
7. Responsive Media Queries (@media max-width: 1024px, @media max-width: 768px)

Third: Detailed Breakdown of Variables, Selectors & Rules

1. CSS Custom Properties (Variables in :root)

Variable Name Value Purpose & Rationale
--color-bg-overlay rgba(240, 245, 241, 0.35) Translucent veil tinting the dark areas of the wallpaper to maximize text contrast.
--glass-bg rgba(255, 255, 255, 0.86) Primary frosted glass surface opacity for main panels, tables, and cards.
--glass-bg-subtle rgba(255, 255, 255, 0.72) Subtle translucent fill for nested sub-cards and stat boxes.
--glass-bg-solid rgba(255, 255, 255, 0.96) High-opacity glass surface for critical modal dialogs.
--primary-green #059669 Primary brand accent color (solid emerald green).
--primary-green-hover #047857 Darker solid emerald green for button hover states.
--danger-red #dc2626 Solid crimson for destructive actions (block, delete, remove).
--warning-amber #d97706 Solid amber for warnings and caution states.
--text-main #0f172a Deep slate text color providing AAA readability on frosted glass.
--blur-strength 16px Standard backdrop-filter blur radius for glass panels.

2. Key CSS Classes

  • .glass-panel: Core glassmorphism utility class. 
    background-color: var(--glass-bg);
backdrop-filter: blur(var(--blur-strength));
-webkit-backdrop-filter: blur(var(--blur-strength));
border: 1px solid var(--glass-border);
box-shadow: var(--glass-shadow);
border-radius: var(--radius-lg);
  • .wallpaper-veil: Fixed overlay position with pointer-events: none that brightens background image highlights without interfering with UI clicks.
  • .svg-icon: Standardized 1.25rem inline vector icon wrapper with stroke: currentColor and fill: none.
  • .btn-primary, .btn-secondary, .btn-danger, .btn-warning: Solid-color button components with smooth micro-interactions.
  • .glass-table: High-contrast data table with separated cell spacing, frosted header styling, and row hover transitions.
  • .modal-backdrop & .modal-card: Accessible fixed-position overlay with flexbox centering and glassmorphic dialog card.
  • .toast & @keyframes toastSlideIn: Dynamic floating status feedback cards with slide-in animation.
